# Netflix-Clone 🎬

A Netflix-inspired homepage created using **HTML5 and CSS3**.

## 👩‍💻 About the Project

This project is a personal frontend development project that recreates the look and feel of the Netflix landing page. It includes a navigation bar, trending movies, membership benefits, FAQs, and footer.

## ✨ Features

- Netflix-style homepage
- Navigation bar with logo and sign-in button
- Hero section with email input
- Trending movies and TV shows
- Hover effects on movie posters
- Reasons to join section
- Frequently Asked Questions
- Footer with useful links
- Responsive design for mobile screens

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to Run

1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Place all images inside the `assets/Images/` folder.
4. Open `index.html` in any web browser.
